# Minecraft — 1.5.0 (Bedrock)

## Update Aquatic — Phase Two

Update Aquatic was completed with Phase Two, adding The Drowned, Sea Turtles, Bubble Columns and more than 150 bug fixes.

## New Features

- Realms became available on Nintendo Switch.
- The Drowned were added.
- Sea Turtles were added, including turtle eggs.
- Added Turtle Shell and Scute items.
- Added the Potion of the Turtle Master.
- Added Nautilus Shells.
- Conduits can be built underwater and provide the Conduit Power effect.
- Added Bubble Columns: Magma Blocks create downward-flowing columns, while Soul Sand creates upward bubbles.
- Added new achievements.
- Added Education Edition world commands: `/ability`, `/immutableworld` and `/worldbuilder`.

## Changes

- Updated the menu background for Update Aquatic.
- Undead mobs now sink in water and can walk along the bottom.
- Improved boat steering with keyboard and mouse.
- Dolphins can be given fish and will swim toward nearby Ocean Ruins or Shipwrecks.
- Updated water-related behavior for several mobs and improved surface swimming.
- Updated several textures and animations.
- The default Field of View was reduced from 70 to 60 and can be adjusted in Video Settings.
- Moved the Inventory button to the top of the Store page.

## Fixes

The supplied 1.5.0 notes include more than 150 fixes across crashes and performance, general behavior, gameplay, items, mobs, blocks, world generation, graphics, audio, the user interface and commands. Examples include improved performance around Ocean Monuments on Android, world synchronization fixes, water-rendering fixes, world-generation corrections and interface improvements.

## Add-Ons

Updated Resource Pack and Behavior Pack templates for 1.5.0 were made available through [Minecraft Add-Ons](https://minecraft.net/addons).
