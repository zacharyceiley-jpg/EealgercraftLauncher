# Minecraft — 1.8.0 (Bedrock)

**11 December 2018**

## New Features

- Pandas now spawn in jungles.
- Stray cats now spawn in villages and can be tamed using fish.
- Ocelots are no longer tameable, but players can feed them to gain their trust.
- Bamboo can be found while fishing in jungles and in some chests.
- Scaffolding was added as a climbable block crafted using bamboo.
- Added achievements for cats, scaffolding and pandas.
- Added the `randomTickSpeed` game rule.

## For Map Makers and Add-On Creators

- Updated templates for version 1.8.0 with new assets and behaviors.
- Add-Ons can add new entities, particles and animations.
- Functions were added to Bedrock, allowing worlds to run commands from external files.

## Changes

- Phantoms are now afraid of cats.
- Tropical fish were made larger.
- Added a crafting recipe for Packed Ice.
- Several dye items and names were reorganized.
- The splash screen now has an animated loading bar.
- Several game-rule commands can now be used without enabling cheats.
- Added a warning when changing settings on a world template.
- Improved the skin picker and player-mention autocomplete.
- Text-to-Speech can now be enabled on Nintendo Switch.
- Marketplace content can be sorted by update status and rating, and bundles can be purchased.

## Fixes

The 1.8.0 update also includes fixes and improvements across crashes and performance, general gameplay, world loading, multiplayer, items, mobs, blocks, Realms, graphics, audio, the user interface, commands and Add-Ons. The supplied notes list fixes for multiple device-specific crashes, world conversion, performance drops, touch controls, world generation, rendering and interface behavior.

For Add-On details, the original notes point to [Minecraft Add-Ons](https://minecraft.net/addons) and the [Minecraft Wiki function reference](https://minecraft.wiki/w/Function_(Bedrock_Edition)).
